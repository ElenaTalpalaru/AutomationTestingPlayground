    API Information

    Base URL

    https://jsonplaceholder.typicode.com

    Available Endpoints

    • GET /todos - Get all todos
    • GET /todos/{id} - Get specific todo
    • POST /todos - Create new todo
    • PUT /todos/{id} - Update todo
    • DELETE /todos/{id} - Delete todo

    Response Format

    {
  "userId": 1,
  "id": 1,
  "title": "delectus aut autem",
  "completed": false
}
