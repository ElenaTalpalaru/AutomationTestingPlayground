### For Automation Testing
here is the published page: 
https://elenatalpalaru.github.io/AutomationTestingPlayground/


These web app provide a comprehensive environment for practicing automation testing with tools like:
- Selenium WebDriver
- Cypress
- Playwright
- TestCafe
- Puppeteer
- And other automation frameworks

## UI Testing Elements Available

The page includes multiple interactive elements specifically designed for automation testing:

- **Dropdowns**: Element selection and text verification
- **Alerts**: Different types of browser dialogs
- **Checkboxes**: Show/hide content based on selection
- **Input Fields**: Text validation with different rules
- **Dynamic Content**: Loading states and dynamic DOM updates
- **Tables**: Sortable data and table interactions
- **Drag and Drop**: Element movement between containers
- **Progress Bar**: Visual progress tracking
- **Images**: Display toggling and state changes
- **Hover Effects**: Mouse interaction events
- **Radio Buttons**: Option selection and result display
- **iFrames**: Cross-frame content interaction

## UI Automation Testing Tips

- Use unique IDs for element selection (all critical elements have IDs)
- Test different waiting strategies with the dynamic content section
- Practice handling alerts and dialogs with the alert section
- Verify conditional visibility with the checkbox section
- Test form validation with the input fields section

## For Testing Backend data

Loading states to test async behavior
Error handling with error messages
Success messages for operations
Form inputs for TODO ID, title, and completion status
Responsive design for mobile testing

## BE Automation Testing Tips

Testing GET requests: Click "Fetch TODOs" to get all todos, or enter an ID and click "Fetch TODO by ID"
Testing POST requests: Enter a title and select completion status, then click "Create TODO"
Testing PUT requests: Enter an ID and new data, then click "Update TODO"
Testing DELETE requests: Enter an ID and click "Delete TODO"
